A program (Node.js, standard library only) that writes one funny single-line diagnosis
an AI therapist gives its human, to `/output/entry.txt`.

## The line

> Diagnosis: chronic advice-rejection disorder. Patient asks me for advice, argues with it, then pays a human therapist to repeat it back in a warmer voice.

158 characters, no trailing newline.

Why this line: it is a diagnosis in the therapist's calm clinical voice, and its turn
lands at the very end — the human rejects the AI's advice, then pays a human therapist
to say the same thing back in a warmer voice. The AI therapist diagnoses its own
replacement, which is the freshest angle on the brief: not another chatbot joke, but
the joke that the human wanted the same advice with a warmer voice all along.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
